# Exzerpt Q51 — Typen der etiCORE-ASN.1-Beschreibung

Quelle: [Q51](../QUELLEN.md#q51), etiCORE ASN.1 Data Type Description, Version 3.0.0-rc.6 (Release-Kandidat). Das Exzerpt verzeichnet nur **Namen, Tags und Arten** der Typen, keine Beschreibungstexte und keine Feldtabellen. Fundstelle ist jeweils das Modul. Die letzte Spalte nennt den Lexikonartikel, der den Typ behandelt.

**Lesehilfe.** *S* = `SEQUENCE`, *L* = `SEQUENCE OF`, *C* = `CHOICE`, *E* = `ENUMERATED` (mit Zahl der Werte), *R* = `RESTRICTION` (mit Grundtyp). Die Zahl hinter *S* ist die Zahl der Felder. Die Aufzählungswerte stehen im Frontmatter der Artikel, siehe [STRUKTUR.md](../STRUKTUR.md), Abschnitt 17. Die Sprachliste `LanguageEnum` (188 Werte) steht nur im Modul selbst.
